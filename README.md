## 先分清：云电脑租用其实有两类东西

**带显卡的云电脑。** 云端是一台真机器，配 vGPU 或独立显卡，通过远程桌面（RDP）连上去用。它的卖点是显卡：云游戏、3D 渲染、AI 出图、视频转码离了显卡跑不动。

**普通云服务器装 Windows。** 没有独立显卡，但便宜得多，1 核 1G 的入门机型 25 元/月，4 核 8G 也只在一百出头。办公、写代码、挂机跑脚本、当跳板机，够用。

最多见的浪费是：花显卡机的钱，干文档机的活。所以先想清楚你的软件到底要不要 CUDA 或独立显存，再往下看。

## 按小时还是按月：计费方式决定一半的钱

带显卡的机型一般有两种收费法。雨云把这两档叫「日常网吧型」和「算力长租型」，名字直白，逻辑也简单：

- **日常网吧型**：每月固定交一笔小钱，送你几个小时额度，之后按开机时长付费，关机不计时。深圳那台 Tesla V100 是 28 元/月含 5 小时，超出后 2.5 元/小时，也可以买 12 元 5 小时、50 元 24 小时的加时包。
- **算力长租型**：整月固定价，随便开，不按小时算。同一台机器 638 元/月。

划不划算，算一下就出来。网吧型每天用 2 小时，一个月约 28 + 2.5 × 60 ≈ 178 元，比长租便宜四分之三还多；每天 4 小时，成本爬到 328 元；真要跟 638 元的长租拉平，得用到 244 小时/月，也就是**平均每天开机超过 8 小时，长租才更省钱**。

偶尔上去打几局、跑一次渲染的，别碰长租型。

## 按用途对号入座

### 挂机（游戏日常、签到、自动化脚本）

4 核 8G 够用，预算再紧一点 2 核 4G 也能跑。计费上按天看：每天挂不满 2 小时，选动态计费或「日常网吧型」；24 小时不关机，固定计费或长租型。挂机对显卡没要求，别为 GPU 加钱。

### 云游戏串流

必须有显卡，而且要接受延迟现实：这类远程串流普遍在 100ms 上下，动作类游戏手感会有折扣。按使用频率选：一周玩两三次，深圳的 28 元/月 + 2.5 元/小时最合适；天天开黑，再考虑长租型的 638 元/月。

### 远程办公、开发

25 元到 68 元的 KVM 档位就够了。国内线路延迟低，美国/香港机型适合需要访问境外服务的情况。注意大陆机房的 HTTP 业务要用自己的域名，需要先备案过白。

### AI 出图、跑小模型

显存是硬门槛。不少模型要求至少 8G 内存/显存，所以 P40 的旗舰版（16 核 16G，8G 显存，258 元起）或广州 RTX3080（10G 显存）更合适。有博主实测过宿迁的 8 核 8G P40 机型：LemonBench 单核 947、多核 7540，Geekbench 6 单核 661、多核 3552，PyTorch 跑 4096×4096 矩阵乘法约 50ms，而同样任务切到 CPU 要 300ms 左右——差距摆在那，值不值看你跑什么。

### 3D 渲染、视频剪辑

吃显存也吃 CPU 核心数。宁波 16 核 16G / 广州 12 核 24G 这两档更稳，硬盘记得留出素材空间。

## 一个容易被忽略的细节：RDP 有没有为 GPU 优化

雨云对 Windows 远程桌面做过针对性调整：启用了 NVIDIA 的 RDP OpenGL 支持，所以能在远程桌面里直接跑 OpenGL 软件并调用 GPU；启用了 H.264/AVC 硬件编码，看视频会走显卡编码；帧率上限也从默认的 30FPS 提到了 60FPS。这几项在系统组策略里能查到，不需要自己折腾。

对只想「租台机器当电脑用」的人来说，这个优化比多给两核 CPU 更实用。用不惯的话，官方也说明可以手动关掉相关选项。

## 买之前该确认的五件事

**NAT 还是独立 IP。** 部分低价机型走 NAT，和别人共用一个公网 IP，可以设置端口转发，但没有独立 IP。需要对外提供服务、或者要挂的东西对 IP 有要求，就得加钱买独立 IP——有些机房的独立 IP 因为带高防，比机器本身还贵。

**上行和下行不是一回事。** 表里的带宽多是「上行 X M / 下行 Y M」，下载快不代表上传快，做直播推流、串流回传主要看上行。

**域名和备案。** 大陆机房上跑 HTTP 业务，需要域名备案并过白后才能用域名访问。

**系统选择。** 支持 Linux 和 Windows，部分地区可装 Mac 系统。显卡机建议直接选 Windows，驱动和 CUDA 环境官方已经装好。

**价格会动。** 官网常做全场 8 折、游戏云季付 6 折这类活动，标价和活动价差距不小。上面所有数字来自公开信息整理，下单前以官网当前页面为准。
